# 五运六气 · 本地查询工具

据《素问》七篇大论（天元纪/五运行/六微旨/气交变/五常政/六元正纪/至真要）、《医宗金鉴·运气要诀》、《三因极一病证方论》运气十六方，实现**可复算、可验证**的五运六气推演工具：

- **年盘**：岁运（五音太少·太过不及）、司天在泉、客气六步排布、客主加临顺逆、天符/岁会/太一天符/同天符/同岁会、运气相临（顺化/天刑/小逆/不和）、平气判定、三化数、灾宫、逐岁病候（《六元正纪》全文）、五星天象、郁发先兆、岁宜药食宜、运气方（《三因方》十六方含六步加减）
- **月盘**：任意日期定位六步气、主客气加临、主运客运五音太少、本步病候与用药方向
- **八字先天**：生年岁运禀赋 + 四柱藏干加权五脏谱 + 先天不足脏腑
- **出生地禀赋**：《异法方宜论》五方民病 + 省级气候修正
- **成年风险**：弱脏 × 生年岁运 × 出生地三源合并的疾病注意清单
- **生活调摄**：《脏气法时论》五脏宜食味 + 《四气调神大论》起居 + 情志忌宜 + 八段锦导引
- **流年预警**：先天弱脏 × 流年岁运克伐交互（高/中/低风险 + 方向）

**在线使用（GitHub Pages，零安装）**：打开仓库 Pages 地址即用——引擎在浏览器本地计算，生辰数据不上传。

## 本地运行

无需任何依赖（纯 Node.js 内置模块）：

```bash
git clone https://github.com/kuaizi369/wuyun-liuqi.git
cd wuyun-liuqi

# 测试（54 项断言）
node test-yunqi.js

# Web 界面
node server.js 3789        # → http://localhost:3789

# CLI
node cli.js year 2026                    # 年盘
node cli.js month 2026-05-10             # 月盘
node cli.js bazi 1990-05-01T08:30 广州   # 八字先天禀赋（含出生地）
node cli.js warn 2026 --birth 1990-05-01T08:30 --loc 广州   # 流年交互预警
```

## API（server.js 模式）

```
GET /api/year?y=2026
GET /api/month?date=2026-05-10
GET /api/bazi?birth=1990-05-01T08:30&location=广州
GET /api/warn?y=2026&birth=1990-05-01T08:30&location=广州
```

浏览器静态模式（GitHub Pages）下页面自动切换为 `window.WUYUNQI` 本地引擎，同一页面双端可用。

## 结构

```
├── index.html        Web 界面（静态双模式：本地引擎 / HTTP API）
├── bundle.js         浏览器打包产物（build.js 生成，勿手改）
├── build.js          CommonJS 依赖图打包器
├── cli.js            命令行（year/month/bazi/warn）
├── server.js         本地 HTTP 服务
├── lib/
│   ├── laws.js       规则层：干支化运化气/六步/三气之纪/四套治则/郁发/天象/病机纲
│   ├── data60.js     数据层：六十年逐岁运气病治全表 + 六司天政六步病候 + 运气方
│   ├── yunqi.js      推演引擎
│   ├── bazi-yunqi.js 八字结合 + 出生地禀赋 + 生活调摄
│   ├── almanac/      八字四柱/真太阳时/行政区划解析（复用 lunar-javascript）
│   └── lunar.js      [lunar-javascript](https://github.com/6tail/lunar-javascript) (MIT, © 6tail)

└── test-yunqi.js     54 项断言测试
```
